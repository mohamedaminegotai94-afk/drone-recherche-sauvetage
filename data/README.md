# Données

Ne pas versionner de gros fichiers vidéo, de sacs ROS ou de poids de modèles dans Git. Les instructions de téléchargement, sources, licences, versions et sommes de contrôle doivent être documentées ici.

Séparer les images utilisées pour l'entraînement et celles réservées aux essais. Les images synthétiques peuvent servir à valider le pipeline, mais ne prouvent pas que le détecteur fonctionnera dans un vrai bâtiment.
